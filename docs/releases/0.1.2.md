# Skep 0.1.2

This release turns builder customization into a proper native terminal
experience.

- Open builder and host shells in a dedicated, independently resizable macOS
  window instead of a fixed sheet.
- Copy terminal selections directly to the Mac pasteboard with Command-C, the
  toolbar, or the context menu.
- Paste from the Mac pasteboard with Command-V or the toolbar and support
  Select All with Command-A.
- Forward OSC 52 clipboard writes from OpenCode and other terminal applications
  through tmux to the local Mac clipboard.
- Repair tmux clipboard forwarding automatically when existing builder and
  workspace terminals open, and configure it during new builder setup.
- Preserve precise trackpad and momentum scrolling without the previous doubled
  scroll sensitivity.
- Keep native macOS window and application shortcuts such as Command-W and
  Command-Q working while the terminal has focus.

The application and update are Developer ID signed, notarized by Apple, and
delivered through Skep's signed Sparkle update feed.
