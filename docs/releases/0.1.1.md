# Skep 0.1.1

This release adds complete, deliberate removal of Skep from a remote Linux VM.

- Keep the existing preservation path as **Uninstall, keep data**.
- Add a permanent remote-host danger zone on the Overview page.
- Add **Erase all data**, protected by exact host-name confirmation.
- Stop every Skep-managed microVM before deleting `/var/lib/skep`.
- Remove all builders, workspaces, templates, Docker volumes, exports,
  Microsandbox files, helpers, systemd integration, sudo rules, sockets, and the
  Skep operator group while leaving the underlying VM intact.
- Rename the sidebar action to **Forget host** so it cannot be confused with
  uninstalling software from the VM.

The application and update are Developer ID signed, notarized by Apple, and
delivered through Skep's signed Sparkle feed.
