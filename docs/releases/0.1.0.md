# Skep 0.1.0

Private beta foundation for isolated, persistent development workspaces.

- Run Microsandbox-backed builders and workspaces on Apple Silicon Macs.
- Connect to Linux hosts through regular SSH or Google Cloud IAP.
- Publish reusable templates and keep workspace terminals attached in the sidebar.
- Automatically align local and remote Skep services with the installed Mac app.
- Reconnect workspace terminals after sleep and transient network loss.
- Add the official Skep app icon and matching website identity assets.
- Add a signed, notarized drag-to-Applications DMG installer and force macOS to refresh the application icon for machines that cached the earlier iconless beta.
- Report expired Google Cloud sessions consistently across host and workspace views, with browser-based reauthentication and explicit retry actions.

This private beta is Developer ID signed, notarized by Apple, and delivered through a signed Sparkle update feed.
