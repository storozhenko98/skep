PRIVACY / OPEN SOURCE

Skep keeps orchestration local.

Application data

Skep stores host connection metadata and application preferences on your Mac. It does not store SSH private keys, Google Cloud credentials, or host passwords.

Network access

Remote connections use OpenSSH or the Google Cloud CLI already configured on your Mac. Host control traffic travels through those connections to a host-local Unix socket. Local workspaces use a private Unix socket on your Mac.

Website

This launch site does not currently use advertising trackers, analytics cookies, or account registration. Vercel may process standard request metadata to operate the hosting service.

Updates

The Mac app checks a public Sparkle update feed hosted with this site. That request can include ordinary network metadata such as an IP address and user agent. Anonymous system profiling is disabled.
