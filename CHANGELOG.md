# Changelog

All notable changes to Skep are documented in this file. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use
[Semantic Versioning](https://semver.org/spec/v2.0.0.html) for the user-facing
version plus a monotonically increasing macOS build number.

## Unreleased

### Changed

- Prepared the source repository for public collaboration under Apache-2.0.
- Corrected bundled third-party notices and separated acknowledgments from
  redistributed dependency licenses.
- Removed generated website and release artifacts from version control.

## 0.1.2 - 2026-08-10

- Reworked builder and workspace terminals as dedicated, resizable native
  windows with Mac clipboard integration and precise trackpad scrolling. See
  [docs/releases/0.1.2.md](docs/releases/0.1.2.md).

## 0.1.1 - 2026-08-10

- Added complete, typed-confirmation removal of Skep-managed data from a remote
  Linux host. See [docs/releases/0.1.1.md](docs/releases/0.1.1.md).

## 0.1.0 - 2026-08-10

- Shipped the first signed and notarized Skep beta. See
  [docs/releases/0.1.0.md](docs/releases/0.1.0.md).
