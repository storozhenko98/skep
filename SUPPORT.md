# Support

Use [GitHub Issues](https://github.com/storozhenko98/skep/issues) for
reproducible bugs and focused feature requests. Include the Skep version, macOS
version, host operating system, connection type, and relevant sanitized logs.

Do not post credentials, private keys, cloud project identifiers, IP addresses,
or complete host inventories. Security reports belong in the private channel
described in [SECURITY.md](SECURITY.md).

Skep is beta software maintained on a best-effort basis. There is currently no
guaranteed response time or commercial support contract.
